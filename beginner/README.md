# 🟢 Beginner Workshops

> Hands-on workshop materials designed for students taking their first steps in Python, data exploration, and foundational machine learning.

---

## 📚 Curriculum & Available Workshops

### 1. Python for AI & Vectorized Computing
- **Topics:** Python 3.10 setup, VS Code essentials, NumPy array vectorization, broadcasting, and calculating matrix operations.
- **Duration:** 2 Hours (Hands-on Lab)
- **Prerequisites:** None.
- **Interactive Lab:** [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AIMLCLUBOCT/Workshops/blob/main/beginner/notebooks/01_python_numpy_basics.ipynb) [`01_python_numpy_basics.ipynb`](./notebooks/01_python_numpy_basics.ipynb)

### 2. Exploratory Data Analysis & Visual Storytelling
- **Topics:** Pandas DataFrame wrangling, handling missing values, filtering rows, and generating charts with Seaborn and Matplotlib.
- **Duration:** 2.5 Hours
- **Prerequisites:** Basic Python syntax.
- **Interactive Lab:** [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AIMLCLUBOCT/Workshops/blob/main/beginner/notebooks/02_exploratory_data_analysis.ipynb) [`02_exploratory_data_analysis.ipynb`](./notebooks/02_exploratory_data_analysis.ipynb)

### 3. Intro to Machine Learning: From Zero to Classification
- **Topics:** Supervised learning intuition, train/test splitting, training Decision Trees and Random Forests using scikit-learn, and reading a confusion matrix.
- **Duration:** 3 Hours
- **Prerequisites:** Python and basic statistics.
- **Interactive Lab:** [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AIMLCLUBOCT/Workshops/blob/main/beginner/notebooks/03_intro_machine_learning.ipynb) [`03_intro_machine_learning.ipynb`](./notebooks/03_intro_machine_learning.ipynb)

---

## 🚀 How to Run

### In the Cloud (Free GPU / No Setup):
Click any of the **Open in Colab** badges above to execute the code directly in your browser.

### Locally on Your Machine:
```bash
git clone https://github.com/AIMLCLUBOCT/Workshops.git
cd Workshops/beginner
pip install -r ../requirements.txt  # or: pip install numpy pandas matplotlib seaborn scikit-learn jupyterlab
jupyter lab notebooks/
```
